# Invitation Nation — React Home Page

A React/Vite recreation inspired by the supplied Invitation Nation wedding-invitation screenshots.

## Run
1. Install Node.js 18+.
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev
4. Open the localhost URL shown by Vite.

## Build
npm run build

The production files will be in `dist/`.

## Included
- Sticky Home / Story / Gallery navigation
- Wedding hero section
- Animated falling petals
- Scroll-reveal animations
- Floating floral imagery
- Live countdown to 26 Nov 2026
- Couple story sections
- Wishes form with sparkle interaction
- Wishes display card
- Gallery
- Floating call / sound controls
- Responsive layout

The supplied screenshots were used as visual references for the included local image assets.
